# US-5.4 – Show Masked Card Number on Receipt

## Card

As a **Customer**, I **MUST** see a masked Card number on every printed Receipt so that I can identify which Card was used without exposing the full Card `cardNumber`.

## Conversation

- Whenever the Customer opts to print a Receipt (BP step 5.3), the ATM retrieves the Card `cardNumber` from the current Session and masks it, showing only the last four digits (e.g. `**** **** **** 1234`).
- The masked Card `cardNumber` is included in the Receipt `content` alongside the Transaction details and the Account `balance`.
- This applies to every Transaction type: `WITHDRAWAL`, `BALANCE_INQUIRY`, and `TRANSFER`.
- Corresponds to activity diagram steps in [Print Receipt](../../use_case/print_receipt/printReceipt.md): "ATM retrieves Card cardNumber from Session and masks it" → "ATM generates Receipt with Transaction details, Account balance, and masked Card cardNumber".
- KANO: **Basic** — Customers expect their card to be identified on a receipt; displaying it masked is a standard banking practice. Its absence would cause confusion, while its presence is taken for granted.

## Confirmation

- **Given** a Transaction with status `COMPLETED` exists in the current Session
  **When** the Customer chooses to print a Receipt
  **Then** the Receipt `content` includes the Card `cardNumber` masked to show only the last four digits (e.g. `**** **** **** 1234`).

- **Given** a Transaction with status `COMPLETED` exists in the current Session
  **When** the Customer chooses to print a Receipt
  **Then** the full Card `cardNumber` is never printed on the Receipt.
