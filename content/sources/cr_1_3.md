# CR-1.3 – Move to OKF Product Documentation

A documentation change requested on 2026-09-12. It changes no behaviour of the ATM system.

---

## Request

Requested by the owner on 2026-09-12, after a first run of `/okf-check` found the documentation
conformant with the Open Knowledge Format (OKF) v0.2 but meeting only 12 of the 41 checks in the
register. The owner asked for three things:

- implement the assessment's recommendations, with one exclusion: no generated root `index.md`;
- explain the repository to each of its audiences — technical readers in `README.md`, students in
  `index.html`, first-time readers on the documentation home;
- present the repository as **okf-productdocumentation**, step 2 of a two-step educational series
  after okf-llm-wiki, with the OKF-based documentation in front and Jarvis as the agent that helps
  with the requirements analysis.

## Decisions

- **No functional change.** No entity attribute, process step, use case flow, state or acceptance
  criterion changes, so this change produces no user stories.
- **Entities and actors** get one page each, in `domain_model/entities/` and `use_case/actors/`.
  The class diagram stays the single description of the relationships.
- **Sources follow the derivation chain**, written as bundle-absolute paths with kebab-case ids that
  footnotes cite. Artifacts this change created or restructured also cite this change request.
- **`generated:`** is `by: jarvis/1.0` — the agent and the version of its instructions, not a model.
  **`verified:`** is never written by Jarvis; the owner records an approval with `make verify`.
- **Tags** are the domain entities an artifact names, plus release row and KANO class on a user story.
- **`content/log.md`** is generated from the change log; the change log stays the only place a
  version is written.
- **Home page** is titled *OKF Product Documentation – ATM System* and gains *What this is*, *How
  the artifacts interlink* and *Learn more*; the story count is corrected to 16.
- **Landing page** becomes a plain-language explainer, neutral in voice and OKF first; **README**
  becomes the complete technical reference.
- **Repository and site** move to `okf-productdocumentation` and
  `https://www.wlrm.ch/okf-productdocumentation/`. The agent keeps the name Jarvis.
- **Assumption:** the existing artifacts were written by Jarvis, as this repository describes.
