# CR-1.7 – Lead with the Open Knowledge Format

A documentation change requested on 2026-09-13. It changes no behaviour of the ATM system.

---

## Request

Requested by the owner on 2026-09-13. After the rename in [CR-1.6](cr_1_6.md), the entry pages still
introduce the repository as Jarvis's. The focus moves to the Open Knowledge Format (OKF) based
product documentation; Jarvis stays, named as the agent that helps with the requirements analysis.
The three entry pages are the README, the landing page and the documentation home.

## Analysis

- **README** opens with "Meet Jarvis", a course promotion and an image; OKF appears only in the third
  section.
- **Landing page** is written in Jarvis's first person ("Hi, I'm Jarvis"), and OKF is one section near
  the end.
- **Home** says in its title, description and *What this is* that Jarvis writes the documentation;
  OKF is mentioned once, in passing.

The artifacts themselves, the instructions and the `jarvis/1.0` stamp are not affected.

## Decisions

- **Landing page voice** — neutral and OKF first: the page describes the documentation in the third
  person, and Jarvis appears in the change flow as the agent doing the requirements analysis.
- **Home title** — renamed to *OKF Product Documentation – ATM System*, and the site title with it.
  The sidebar label stays *Home*.
- **README** — opens with what the repository is; the image is removed from the repository; the
  course promotion is kept, after the introduction.
- **Agent name and stamp stay** — Jarvis and `jarvis/1.0`, as decided in CR-1.6.
- **Version markers** — the v1.5 marker comes off the home page, as the change log's cleanup rule
  requires two versions on.
- **Earlier change requests keep their wording**: they record what was true when they were written.
