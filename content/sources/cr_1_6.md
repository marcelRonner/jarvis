  link step 1; the check register names okf-llm-wiki as the repository it shares its checks with.
- **Earlier change requests and the 2026-09-13 assessment keep the old name**: they record what was
  true when they were written.
- **Version markers** — the v1.4 marker comes off the home page, as the change log's cleanup rule
  requires two versions on.
- **Assumption:** GitHub redirects the old repository address after the rename, so existing clones and
